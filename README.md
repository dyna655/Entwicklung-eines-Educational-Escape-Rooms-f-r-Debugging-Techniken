# Ad Astra: Educational Escape Room für Debugging-Techniken

GitHub Seite des Educational Escape Rooms **„Ad Astra“**. Dieser Escape Room wurde im Rahmen einer Bachelorarbeit entwickelt, um Programmieranfängern den Einstieg in systematisches Debugging, Code-Tracing und den Umgang mit IDE-Debbuggern spielerisch näherzubringen.

---

## 1. Online-Version (Escapp)
Wenn du den Escape Room direkt im Browser spielen möchtest, ohne lokal eine eigene Instanz zu installieren, kannst du die offizielle gehostete Version nutzen:

**[Hier geht es zur offiziellen Online-Version von „Ad Astra“](https://escapp.es/escapeRooms/1053/join)**
